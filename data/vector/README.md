# Vector Data Directory

This directory contains shapefiles for Ethiopia and its regional administrations. Ensure the following files are present:

1. `eth_admbnda_adm0_csa_bofedb_2021.shp`: Shapefile for Ethiopia as a whole.
2. `eth_admbnda_adm1_csa_bofedb_2021.shp`: Shapefile for Ethiopia's regional administrations.

If these files are missing, please download them from the official source or provide the correct paths.
