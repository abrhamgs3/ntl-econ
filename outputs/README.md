# Outputs Directory Structure

- figures/
  - regional/: Regional NTL plots
  - national/: National NTL plots
  - combined/: Combined NTL plots
  - ntl_trends/: NTL trend plots for each region
  - regression/: Regression result plots
  - panel_fit/: Panel fit plots for each region
  - panel_trend/: Panel trend plots for each region
- results/
  - regional/: Regional regression summaries and results
  - national/: National regression summaries and results
  - combined/: Combined regression summaries and results
- data/: Output data files (Excel, CSV)
- scripts/: Output scripts or logs
- logs/: Log files
- tables/: Summary tables

All analysis outputs, plots, and results are now organized in these folders for easy access.
